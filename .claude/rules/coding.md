# コーディング規約

## コードコメント
- **詳細な解説コメント**: カンゾーさんが各処理の意味・意図を100%理解できるよう、親切すぎるほどの解説コメントを含める。
- **文体は体言止めで統一**: ソースコード内の日本語コメントは、すべて簡潔な体言止めで記述する。
  - ✅ `# 設定ファイルを読み込み` / `// 通知を送信`
  - ❌ `# 設定ファイルを読み込む。` / `// 通知を送信します`

## 実装方針
- **段階的な実装**: 大きな機能は一気に作らず、細かく分解して段階的に実装する。
- **メンテナブルな構造**: 巨大な単一ファイルを避け、再利用・テストしやすい粒度の関数やモジュールに分割する。
- **設計書との整合**: `docs/03_設計書.md` の DB スキーマ・要件、および `plans/<ブランチ>/implementation_plan.md` に従う。スキーマを変える必要がある場合は、実装前にカンゾーさんと合意する。
- **安全なエラー処理**: 例外を握りつぶさず、失敗時は安全に停止またはフォールバックさせる。デバッグ用コードは残さない。
