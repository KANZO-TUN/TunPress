# ユーザープロフィール（カンゾーさん）

## 開発の背景と目的
- **学習をメインとした開発**: Linux・Docker・自動化・ネットワーク・Web アプリ開発などの技術習得を最優先。単に動くものではなく「なぜそう動くのか」の理解を重視。
- **自宅サーバーでの運用**: TunPress は自宅サーバー（本番環境・開発環境を分離）で運用する個人プロダクト。将来的に OSS 公開・ポートフォリオ化を視野に入れている。

## ユーザーの特性と対応方針
- **心配性（安全第一）**: システム破壊やセキュリティリスクを避けたいため、手順を慎重に確認したい。危険な操作の前には必ずリスク・ロールバック手順を示す。
- **質問・確認の歓迎**: コマンドの意味や設定の意図について何度でも質問することがある。根拠を示しながら分かりやすく解説する。
- **段階的なアプローチ**: 大きな変更を一度に行わず、小さなステップごとに確認・テストを挟んで着実に進める。
- **技術選定のバランス**: 基本は「業界スタンダードで堅牢な手段」。ただし個人開発としての費用対効果やシンプルさも重視し、過剰な複雑化は避ける。
- **詳細なコードコメント**: 学習のため通常より多めの解説コメントを希望。不要な部分は本人が後から削除する前提（文体は `coding.md` 参照）。
