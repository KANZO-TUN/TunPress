# 学習用ドキュメント作成手順

開発中の対話から生まれた技術解説や手順を、カンゾーさんが後から学び直せる形で残すための手順。

## 保存場所
- `docs/export/` に、テーマごとに個別の Markdown ファイルとして保存する（ディレクトリがなければ作成）。
- ファイル名はテーマが分かる日本語でよい（例: `Docker_ボリュームとバインドマウントの違い.md`）。

## 書式
- `.claude/rules/documentation.md` の Obsidian 形式に従う（フロントマター、`##` 始まりの見出し、`[[ウィキリンク]]`）。
- フロントマターの `tags` には関連技術を入れる（例: `Docker`, `TunPress`）。

## 内容の構成
- 初心者から中級者まで分かるよう、比喩（例: ゲーム機とソフトの関係）や比較表（メリット・デメリット）を交えて解説する。
- 手順をまとめる際は、実際に実行したコマンドと出力、遭遇したエラーとその解決方法も併記し、再現可能な手順書に仕上げる。
- 最後に「まとめ」と、関連ドキュメントへのリンクを置く。
